# Professional framing and rewritten request

## What a specialist would add

Separate memory addressing, memory correction, and statistical evidence
accumulation. Identify which property the query/key Gram matrix must have for
each objective. Check the rank and write-interference consequences of a feature
map before testing a new architecture. Compare functional equivalence under
softmax with equivalence under recurrent writes; the two need not coincide.
Screen the uncertainty-memory literature before claiming a new concept.

## Raw starting material

Start with the original DeltaNet recurrence and regression loss, the Gated
DeltaNet recurrence, the exact ArithScope Ramanujan kernel and residue-feature
implementation, individual noisy observations, and the exact generating law.
Use primary papers, including the recent Kalman Delta Networks preprint.
Main summaries provide context; they are not evidence for this branch.

## Methods and tools

Use Hilbert-Schmidt operator geometry, affine projections, contraction bounds,
Gram ranks, signed causal influence matrices, exact Ramanujan identities,
direct-sum versus tensor-product features, and online mean/precision recurrences.
Check with `fractions.Fraction`, exact Gaussian elimination, the unchanged
arithmetic oracle, float64 PyTorch autograd, a separate triangular matrix
implementation, and deterministic fresh-data mechanism probes. Use SHA-256,
replay, unit tests, and the registered interpreter. Install nothing.

## Independent criteria of correctness

Displayed proofs, exact arithmetic, a second update implementation, autograd
for the regression gradient, a Bayes posterior oracle, falsifying rank and
change-point examples, preserved observations, and deterministic replay can
establish the bounded results. Learned-model usefulness still requires a new
prospective matched-budget experiment on independent data and model seeds.

## Rewritten prompt

In an isolated ArithScope subdirectory, determine whether its arithmetic
Hilbert-space features can provide useful QKV addressing and evidence
accumulation for DeltaNet. Start from the original recurrent update and the
exact kernel rather than from architectural labels. Derive the conditions for
stable writes, independent retrieval, and confidence growth. Identify feature
rank obstructions and counterexamples, including the distinction between
softmax-equivalent kernels and recurrent-memory geometry. Construct only the
smallest conditional remedy, and test its identities and failure boundaries
with exact arithmetic, independent matrix recurrences, and fresh causal
observations. Separate known mathematical facts from repository-specific
applications, and mechanism probes from learned-model evidence. Preserve
protocols, inputs, hashes, failed logs, and replay commands. Leave a reviewable
handoff for another chat to decide integration without changing the main line
or the earlier metacognition branch.
