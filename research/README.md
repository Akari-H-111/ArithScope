# Exploratory research (not part of the claim ledger)

Each directory here is a dated, self-contained development study. Nothing in `research/` changes
[`docs/CLAIM_LEDGER.md`](../docs/CLAIM_LEDGER.md) by itself: a result moves into `docs/` only through a preregistered
experiment or a proof copied into [`docs/MATH.md`](../docs/MATH.md) with its label. Files are kept as delivered;
the two 2026-10-15 studies carry a `MANIFEST.sha256` that still verifies.

| Directory | What it asked | Outcome |
|---|---|---|
| [`deltanet_hilbert/2026-10-15/`](deltanet_hilbert/2026-10-15/README.md) | Can exact arithmetic features improve the addressing and evidence handling of a delta-rule memory? | Restoring the constant character turns the T3 simplex comb into orthogonal phase addresses `D_P = 1[P | n]`; an additive count memory on them gives the exact Bayes posterior. Untrained mechanisms only. |
| [`metacognition/2026-10-15/`](metacognition/2026-10-15/README.md) | Does a label-free backward pass add information that a forward evidence state lacks? | No for the uniform-target last-layer gradient (recoverable from forward tensors); counts give the exact posterior under independence and fail under copied observations. |
| [`evidence_readout/2026-10-23/`](evidence_readout/2026-10-23/PROGRAM.md) | Does the count construction of the two studies above become a trainable ArithScope component? | Theory T9 (moved into `docs/MATH.md`), an adversarial audit, development pilots, and the design of E10, which was then preregistered and run ([`docs/PREREGISTRATION.md`](../docs/PREREGISTRATION.md), Section 13). |

The 2026-10-15 studies were written by Codex during the E9 runs; the 2026-10-23 program was run by Claude Sonnet
workers under an orchestrating Claude Opus session. Their own `README.md` and `HANDOFF.md` files give replay commands.
